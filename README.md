# Amiibo Link 本地传输台 · v1.0.0

一个无需安装依赖、可直接通过静态 HTTP 服务运行的 Amiibo Link 网页工具。它支持筛选 Amiibo Link 蓝牙设备、校验并传输本地 BIN、选择设备模式，并查看公开 Amiibo 元数据。

## 启动

首先请克隆/下载本仓库，然后在目录双击`index.html`

## 使用

1. 先唤醒设备，随后点击网页左侧“连接设备”，在浏览器设备选择器中选择你的设备（一般为Amiibo Link）。
2. 选择amiibo `.bin` 文件，或输入下载链接。
3. 网页会自动识别协议，如果传入设备失败，可手动切换协议。如果你的amiibo link是通过小程序写入的，则一般为新版协议，否则应该为旧版协议。
5. 点击“传到设备”，等待页面显示写入完成。

## v1.0.0 范围

- 读取 AmiiboAPI 的公开 JSON 名称和识别 ID，你可以在网页底部找到提供amiibo文件的资源站、网盘与社区链接。
- 仅在当前浏览器内处理本机文件；文件不会上传。公开目录需要联网；第三方 BIN 直链还需要来源站允许 CORS。
- 支持手动无限、按序、旧版读写和新版自动无限模式。新版自动无限模式与恢复出厂设置仅在新版协议下开放。
- 尝试通过 Device Information Service（0x180A / 0x2A25）读取硬件序列号。设备固件未公开该值时，页面会显示“设备未提供可读取的硬件序列号”。
- 页面不会验证 Amiibo BIN 的来源或密码学真实性。当前校验只能排除明显不符合扩展名、长度和 UID 前缀要求的文件。

## 隐私与连接

页面只向 AmiiboAPI 请求公开目录 JSON，并按用户操作读取所选的 HTTPS 文件地址。蓝牙数据和本机 BIN 由浏览器直接处理。协议记忆保存在本机浏览器存储中；不会发送到网页服务端。

浏览器必须支持 Web Bluetooth，并允许该页面连接设备。若自动识别失败，可以在连接前或连接后手动选择协议。浏览器若不支持广播监听，自动识别会在首次成功握手后完成。
